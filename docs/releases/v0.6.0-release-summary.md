## Major Features

### 1. Semantic / Hybrid Retrieval (Task 1: EmbeddingRetriever)

- `EmbeddingProvider` ABC + `FakeEmbeddingProvider` (ngram-based deterministic vectors) + `OpenAIEmbeddingProvider`
- `SemanticRetriever` — full embedding cosine-similarity search (replaces old stub)
- `HybridRetriever` three modes: `keyword` / `semantic` / `hybrid`
- JSON-file embedding cache with model-change auto-invalidation
- Graceful fallback: no API key → keyword-only + warning log

### 2. LLM Summarization (Task 2: LLMSummarizer)

- `LLMProvider` ABC + `FakeLLMProvider` + `OpenAILLMProvider`
- `LLMSummarizer` implementing `BaseSummarizer`
- 3 summary types: `brief` / `semantic` / `memory`
- Long-text chunk → summary → merge pipeline
- `EnhancedSummaryResult` with entities, key_points, open_questions, metadata
- Fallback: no LLM key → `RuleBasedSummarizer` with `mode=rule_fallback`

### 3. Slash Command Handler System (Task 3: CommandRegistry)

- `commands/` Python package with `Command`, `CommandResult`, `CommandRegistry`
- 4 built-in handlers: `memory:save`, `memory:retrieve`, `memory:rebuild`, `memory:manage`
- Argument validation, structured results, error handling, edit-distance suggestions
- `plugin.json` `commands` section declaring all 4 commands with dual `script` + `handler` paths
- Old `commands/*.md` declarative files preserved as documentation/help

### 4. Memory Lifecycle & Quality Management (Task 4)

- Extended `MemoryRecord` schema: 15 new fields (status, content_hash, ttl_days, tags, access_count, merged_into, etc.)
- Status state machine: `active` → `archived` / `expired` / `merged` / `deleted`
- TTL-based auto-expiry with per-record and global defaults
- Content-hash exact dedup + keyword/embedding-based near-duplicate detection
- `generate_quality_report()` — totals, status distribution, duplicate/expired/low-quality candidates, recommended actions
- `retrieve_memory()` supports `include_expired` and `tags` filtering

### 5. Claude Code Manifest Command Integration

- `plugin.json` v0.6.0 with `commands` section (4 commands)
- `TestManifestCommandIntegration` (5 tests) validating consistency between manifest, registry, and legacy paths
- 3 historical test failures fixed (plugin.json path migration to `.claude-plugin/`)
