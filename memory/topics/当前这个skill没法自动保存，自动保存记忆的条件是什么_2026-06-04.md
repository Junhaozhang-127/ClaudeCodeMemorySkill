## 为什么自动保存不起作用

根本原因在于环境变量不匹配。你的 `post_conversation.sh`（Stop 钩子）依赖两个环境变量：

| 脚本期望的变量 | Claude Code 实际是否提供 |
|---|---|
| `CLAUDE_CONVERSATION_TITLE` | **不提供** |
| `CLAUDE_CONVERSATION_CONTENT` | **不提供** |

当 Stop 钩子触发时，Claude Code **通过 stdin JSON** 传递数据，而不是通过环境变量：

`​``json
{
  "session_id": "abc123",
  "transcript_path": "~/.claude/conversation.jsonl",
  "stop_hook_active": false
}
`​``

Claude Code 实际提供的环境变量是：
- `$CLAUDE_PROJECT_DIR` — 项目根目录
- `$CLAUDE_LAST_MESSAGE` — 最后一条助手消息
- `$CLAUDE_SESSION_ID` — 会话 ID
- `$CLAUDE_PLUGIN_ROOT` — 插件目录路径

因此，脚本运行到第 71-73 行时，两个变量都为空，直接走到错误分支：
`​``bash
echo "[Memory Hook] 无对话内容可保存" >&2
exit 1
`​``

## 需要修复的内容

`post_conversation.sh` 需要重写为：
1. 从 stdin 读取 JSON，提取 `transcript_path`
2. 从 `transcript_path` 读取对话记录文件（JSONL 格式）
3. 将其传递给 `summarize_session.py`
